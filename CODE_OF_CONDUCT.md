# Code of Conduct

Vordain Guard contributors are expected to keep project spaces respectful, technically constructive, and safe.

Be welcoming, disagree with ideas rather than people, respect privacy, and avoid harassment, threats, discrimination, sexualized conduct, or disclosure of another person's private information. Because this project concerns family safety, never post identifiable child or family data.

Project maintainers may edit or remove content and restrict participation when behavior threatens people, privacy, or the project's safety boundaries. Report conduct concerns through a private channel described in [SECURITY.md](SECURITY.md) rather than escalating them publicly.

This code applies to repository discussions, issues, pull requests, and other spaces where someone is representing the project.
